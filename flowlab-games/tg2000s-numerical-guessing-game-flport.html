TG2000's Numerical Guessing Game (Flowlab Port)

Release Date: 11/27/2023 (Original Release), 7/9/2024 (Public Release)

A simple game where you guess the number, ported to Flowlab from the Android version! Play in 4 difficulty modes!

Controls: Enter key to enter a number/select a mode, the up and down keys to select a mode, the backspace key to delete a number, and the number keys to input numbers.

Credits: TheGamer2000 (Rendition Lead, GFX, Code Porting & Programmer, Sound), KingKong (Original Programming)
