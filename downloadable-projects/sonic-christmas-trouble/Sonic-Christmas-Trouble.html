SONIC: CHRISTMAS TROUBLE (DEMO 2)

Lead/Developer(s): Sonic the Dutch Hedgehog, Team Brickheads

Project Description

Help Sonic the Hedgehog stop Dr. Eggman from ruining Christmas! This demo covers three zones and a special stage gauntlet!

You must have a Sega Genesis/Mega Drive console or emulator to play this project.

Note that this project is no longer in development and that the demo is the final version of the project.
