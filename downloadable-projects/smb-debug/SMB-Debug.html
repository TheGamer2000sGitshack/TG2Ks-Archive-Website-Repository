SUPER MARIO BROS. DEBUG MODE FONT GFX

Lead/Developer(s): TheGamer2000

Project Description

A very primitive ROM hack of the original release of SMB1 that replaces all of the text character graphics with the graphics found in Sonic 1 and Sonic 2.

You must have an NES console or emulator to play this project.
