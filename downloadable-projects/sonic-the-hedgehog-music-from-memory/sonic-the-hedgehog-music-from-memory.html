SONIC THE HEDGEHOG: MUSIC FROM MEMORY

Lead/Developer(s): TheGamer2000

Project Description

It's just Sonic the Hedgehog, but all of the tracks were recreated from memory!

The entire recreation process was done using DefleMask and took a total of 3 months to complete.

You must have a Sega Genesis/Mega Drive console or emulator to play this project.
