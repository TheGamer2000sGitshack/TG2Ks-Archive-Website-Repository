THE ORANGE CREATURE FROM GITHUB MADNESS 3 IN SONIC DEBUT

Lead/Developer(s): MDTravis, TheGamer2000

Project Description

A simple (authorized) ROM hack of a ROM hack that simply replaces Debut Sonic with Littlemore Sonic from GitHub Madness 3.

Other than the reskin, the original ROM hack and its assets are courtesy of MDTravis and the Debut development team.

You must have a Sega Genesis/Mega Drive console or emulator to play this project.

Note that none of Littlemore Sonic's moves are present in this hack. Debut Sonic's moves are quite different from the aforementioned character.
