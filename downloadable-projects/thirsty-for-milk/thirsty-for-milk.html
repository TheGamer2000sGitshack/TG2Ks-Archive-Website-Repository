THIRSTY FOR MILK - THE INTERACTIVE STORY

Lead/Developer(s): TheGamer2000

Project Description

You find yourself thirsty for milk! Will you grab a carton before your thirst overwhelms you?

Based on a story I wrote 3 years ago for a cancelled project.

This project is only compatible with modern versions of Windows (This is subject to change).

This project comes in both ASCII and Non-ASCII versions.
